# 시크릿루트 — 아임웹 공통코드 + 본문 위젯 설치
## 초보자용 수정 매뉴얼

**아임웹 기본 헤더·푸터는 그대로 사용합니다. 페이지 위젯에는 본문만 넣습니다.** 이전처럼 페이지마다 긴 스타일·스크립트·설정을 복사하지 않습니다.

## 0. 지금 구조를 먼저 확인하세요

| 담당 영역 | 어디에서 관리하나요? | 수정 위치 |
|---|---|---|
| 로고·메뉴·로그인·장바구니 | 아임웹 기본 헤더 | 디자인 모드 상단 설정 |
| 회사정보·약관 링크 | 아임웹 기본 푸터 | 디자인 모드 하단 설정 |
| 색상·카드·버튼·모바일 스타일 | 공통 Header Code | common/01-header-style.txt |
| 사진 주소·페이지 주소·예시 상품 | 공통 Footer Code의 설정 | common/02-settings.txt |
| 검색·필터·배너 등 동작 | 공통 Footer Code의 스크립트 | common/03-footer-runtime.txt |
| 페이지별 제목·배너·소개 | 해당 페이지 코드 위젯 | content/ 안의 짧은 TXT |
| 상품·옵션·주문·결제·회원 | 아임웹 기본 쇼핑·회원 기능 | 상품 관리자 및 기본 위젯 |
| 실제 문의 접수 | 아임웹 기본 입력폼 위젯 | 문의 페이지의 입력폼 설정 |

**공통코드는 한 번만 설치합니다.** 화면의 Header Code / Footer Code는 상단·하단 디자인을 뜻하는 것이 아니라 모든 페이지에 코드를 넣는 입력칸 이름입니다.

이 설치본에는 헤더·푸터를 삭제·숨기는 코드, 가짜 회원폼, 자체 장바구니·찜·결제 코드가 없습니다. 현재 고객 확인용 GitHub 전체 화면은 디자인 참고용이며, 아임웹 설치 패키지는 아래 본문 분리 구조를 사용합니다.

## 1. 파일 준비

1. 최신 secret-route-imweb-handoff.zip을 압축 해제합니다.
2. imweb-handoff 폴더 안에 common, content, assets가 있는지 확인합니다.
3. 이전 code-blocks 폴더를 사용하지 않습니다. 이전 설치본은 archive-clothing-monolithic-handoff에 기록으로 남겼습니다.

기존에 긴 코드를 붙여넣었다면 그 코드 위젯 내용을 새 content 파일로 교체합니다. **기존 위젯과 새 위젯을 함께 넣지 않습니다.** 다른 사이트 기능이나 기존 공통코드를 지우지 마세요.

## 2. 공통 스타일 설치 — 한 번만

아임웹 관리자에서 **환경설정 → SEO(검색엔진최적화) → 고급 설정 → 공통 코드 삽입**으로 이동합니다. 공통 코드 삽입이 꺼져 있으면 켭니다. 관리자 화면 버전에 따라 위치·표현이 다를 수 있습니다.

1. common/01-header-style.txt를 메모장으로 엽니다.
2. Ctrl + A → Ctrl + C로 전부 복사합니다.
3. 공통코드의 **Header Code** 칸에 붙여넣습니다.
4. 이미 다른 코드가 있다면 지우지 말고 끝에 추가합니다.
5. 저장합니다.

사이트 소유 확인용 메타태그를 넣는 Header Code 상단과 혼동하지 마세요. 이 파일은 style 태그를 포함한 디자인 스타일입니다. 본문의 레이아웃·색상 CSS는 .sr-content 안에 적용합니다. 공통 글꼴은 Pretendard로 기본 헤더·푸터·입력폼에도 적용하며, 제목·강조·버튼 굵기를 명시합니다. 아이콘 폰트는 제외합니다.

## 3. 공통 설정과 동작 설치 — 한 번만

**Footer Code** 칸에 아래 두 파일을 순서대로 붙입니다.

1. common/02-settings.txt 전체를 복사해 붙여넣습니다.
2. 그 아래에 줄바꿈을 넣습니다.
3. common/03-footer-runtime.txt 전체를 복사해 붙여넣습니다.
4. 저장합니다.

설정이 먼저, 동작 코드가 나중입니다. 각 파일은 script 태그를 포함합니다. 다른 분석 스크립트가 이미 있다면 유지하고 맨 아래에 추가합니다. 동일 파일을 두 번 넣지 않습니다.

**이 단계에서 화면이 바로 생기지는 않습니다.** 공통 스타일·설정·동작만 준비된 상태이며, 다음 단계에서 본문 위젯을 넣습니다.

## 4. 메인페이지 본문 — 5개 위젯을 순서대로

디자인 모드에서 메인페이지를 선택합니다. 헤더·푸터는 그대로 둡니다. 그 사이의 본문에 빈 섹션을 준비합니다.

| 순서 | 일반 코드 위젯에 붙여넣을 파일 | 화면 내용 |
|---|---|---|
| 1 | content/home-01-hero.txt | 메인 배너 |
| 2 | content/home-02-products.txt | 카테고리·상품 카드 |
| 3 | content/home-03-editorial.txt | 컬렉션 소개 |
| 4 | content/home-04-best.txt | 베스트 상품 |
| 5 | content/home-05-banner.txt | 하단 안내 배너 |

각 파일마다 다음을 반복합니다.

1. 본문에 일반 **코드 위젯**을 추가합니다.
2. 위젯을 우클릭하고 코드 설정을 엽니다.
3. 해당 TXT를 메모장에서 전체 복사합니다.
4. 코드 입력칸에 붙여넣고 저장합니다.
5. 다음 섹션에 다음 코드 위젯을 넣습니다.

한 파일이 한 영역이므로, 나중에 메인 문구를 바꿀 때는 home-01-hero만 수정하면 됩니다. CSS·JavaScript·상품 전체 데이터는 페이지 코드에 없습니다.

섹션은 배경 #FFFCF8, 불필요한 상하 여백 0, 위젯은 가로 폭 전체로 배치합니다. 코드 내부에 본문 폭과 모바일 여백이 있습니다. 기본 헤더·푸터의 배경·여백은 아임웹 설정에서 따로 맞춥니다.

## 5. 아임웹 기본 헤더·푸터 설정

### 헤더

1. 아임웹 기본 상단 영역의 로고에 assets/logo.png를 업로드합니다.
2. 상단 메뉴에 SHOP, 신상품, 베스트, 컬렉션, 고객센터를 등록합니다.
3. 로그인·회원가입·장바구니는 기본 회원/쇼핑 요소를 사용합니다.
4. 헤더 배경은 흰색 또는 아이보리, 포인트는 #FF781F로 맞춥니다.

### 푸터

기본 하단 영역에서 사업자 정보·연락처·이용약관·개인정보처리방침·배송 안내·문의 링크를 설정합니다. 코드로 대체하지 않습니다. 준비 중 문구를 실제 운영 정보로 교체하세요.

## 6. 나머지 본문 페이지

| 아임웹 페이지 | 기본 주소 | 본문 코드 파일 |
|---|---|---|
| SHOP | /shop | content/shop.txt |
| 신상품 | /new | content/new.txt |
| 베스트 | /best | content/best.txt |
| 컬렉션 | /collection | content/collection.txt |
| 브랜드 소개 | /about | content/about.txt |
| 고객센터 | /support | content/support.txt |
| 배송·교환 | /shipping | content/shipping.txt |
| 이용약관 | /terms | content/terms.txt |
| 개인정보처리방침 | /privacy | content/privacy.txt |

페이지를 만든 뒤 일반 코드 위젯에 해당 파일을 붙입니다. 기본 주소는 사이트 도메인 뒤의 부분입니다. 예를 들어 내사이트/shop입니다. 아임웹 메뉴 주소 입력 형식에 맞게 저장 후 실제 URL을 확인하세요.

상품 상세·로그인·장바구니·찜은 본문 시안 페이지를 만들지 않고 **아임웹 기본 기능을 사용합니다.** 상품 번호 id를 주소에 추가하는 기존 시안 방식은 설치본에서 제거했습니다.

## 7. 실제 문의폼 만들기

문의 페이지를 만들고 주소를 /contact로 맞춥니다. 본문을 다음 순서로 배치합니다.

1. 일반 코드 위젯: content/contact-01-heading.txt를 붙입니다.
2. **아임웹 기본 입력폼 위젯**을 추가합니다. 코드 위젯 밖에 별도 위젯으로 놓습니다.
3. 일반 코드 위젯: content/contact-02-guide.txt를 붙입니다.

기본 입력폼 설정에서 필요한 필드를 추가합니다.

| 필드 | 권장 형태 | 필수 여부 |
|---|---|---|
| 이름 | 짧은 텍스트 | 필수 |
| 답변 받을 이메일 | 이메일 | 필수 |
| 문의 유형 | 선택 항목: 상품/배송/교환/기타 | 필수 |
| 상품명 또는 주문번호 | 짧은 텍스트 | 선택 |
| 문의 내용 | 긴 텍스트 | 필수 |
| 개인정보 수집·이용 동의 | 아임웹 동의 설정 | 운영 정책에 맞게 설정 |

수집·이용 안내는 실제 운영 목적과 보유 기간에 맞게 작성합니다. 알림 수신·완료 안내는 아임웹 입력폼 설정에서 지원하는 옵션을 확인해 설정합니다. 문의가 관리자에게 저장되는지 테스트 문의 1건으로 확인하세요.

**접수 기능은 아임웹 입력폼이 담당합니다.** 코드에는 문의 내용을 저장하거나 가짜 완료 메시지를 띄우는 폼이 없습니다. 문의폼 색상·버튼·폭도 입력폼 위젯 설정에서 조정합니다.

## 8. 관리자 수정 위치 — 한 곳에서 바꾸기

### 상품 카드·사진·링크

공통 Footer Code의 window.SR_SHOP 설정만 수정합니다. 모든 본문 위젯이 같은 설정을 읽습니다. 페이지별로 설정을 다시 복사하지 않습니다.

- products: 예시 상품 카드 목록. 이름·가격·분류·설명을 바꿀 때 이 배열을 수정합니다.
- productUrls: 실제 아임웹 상품 상세 주소. 번호별 주소를 넣습니다.
- imageUrls: 업로드한 이미지 URL. hero, editorial, shirt, knit, denim, jacket, dress, bag 키를 사용합니다.
- links: 디자인 본문에서 이동할 실제 페이지 URL.
- assetBase: 기본 사진 폴더. imageUrls를 설정하면 그 이미지가 우선합니다.

### 상품 연결 예시

공통 설정에서 productUrls의 빈 중괄호를 아래처럼 바꿉니다. 주소는 실제 등록한 상품 주소로 교체합니다.

```javascript
"productUrls": {
  "1": "https://내사이트/실제상품1주소",
  "2": "https://내사이트/실제상품2주소"
},
```

상품 1은 셔츠, 2는 니트, 3은 데님, 4는 재킷, 5는 원피스, 6은 가방입니다. 실제 상품이 다르면 products의 이름·사진·가격도 함께 수정합니다. 연결 주소가 없는 카드는 준비 중 안내를 표시하며 시안 주문 화면으로 이동하지 않습니다.

### 이미지 예시

```javascript
"imageUrls": {
  "hero": "https://cdn.imweb.me/실제메인사진.jpg",
  "shirt": "https://cdn.imweb.me/실제상품사진.jpg"
},
```

실제 이미지 주소를 입력하세요. 기본 헤더의 로고는 공통 설정이 아니라 아임웹 상단 설정에서 업로드합니다.

### 메뉴 주소가 다를 때

```javascript
"shop.html": "/shopping",
"contact": "/inquiry"
```

왼쪽 키는 유지하고 오른쪽 URL만 바꿉니다. 기본 헤더·푸터의 메뉴 링크도 아임웹 디자인 모드에서 별도로 수정합니다.

### 색상·문구

색상은 공통 Header Code의 --sr-accent, --sr-bg, --sr-text 변수를 찾습니다. 변수 적용 외의 세부 요소 색상은 같은 공통 스타일 안에서 수정합니다. 페이지 제목·설명은 해당 본문 위젯만 수정합니다. 배너 전환 문구는 공통 동작 코드의 배너 문구 부분도 함께 수정합니다.

## 9. 실제 쇼핑몰 운영

아임웹 상품 관리자에서 상품·옵션·재고·배송·결제를 등록합니다. 카드에 실제 productUrls를 넣으면 아임웹 기본 상품 상세로 이동하며, 이후 옵션·장바구니·결제는 기본 쇼핑 기능을 사용합니다.

현재 products는 고정 카드 데이터입니다. 아임웹 상품 관리자에서 가격을 바꿔도 자동 동기화되지 않습니다. 상품이 많거나 자주 바뀌면 SHOP·신상품·베스트의 상품 영역은 **아임웹 기본 쇼핑 위젯**으로 대체하고, 제목·배너·컬렉션 소개만 코드 위젯으로 운영하는 것이 좋습니다. 고정 상품 카드 코드와 기본 쇼핑 위젯을 같은 영역에 중복 넣지 않습니다.

쇼핑 위젯으로 전환하면 고정 카드 검색·필터와 같은 동작을 그대로 붙이는 것이 아니라, 아임웹 쇼핑 위젯의 기능과 설정을 사용합니다. 스타일을 세부적으로 일치시키는 추가 작업은 별도 검수가 필요합니다.

## 10. 확장할 때

새 본문은 아래 형태로 작성하면 공통 스타일을 사용할 수 있습니다. data-sr-block 이름은 영역마다 다르게 정합니다.

```html
<div class="sr-content" data-sr-block="campaign-01">
  <div class="wrap panel">
    <h2>새로운 이벤트</h2>
    <p>이벤트 안내를 입력하세요.</p>
  </div>
</div>
```

공통 동작은 .sr-content 블록 안에서만 실행됩니다. 기본 헤더·푸터·입력폼에 이벤트를 붙이거나 입력을 가로채지 않습니다. 입력폼·게시판·회원 기능은 아임웹 기본 위젯을 추가하세요.

- [ ] 실제 상품의 옵션·장바구니·결제는 아임웹 기능으로 동작한다.
- [ ] 모바일 화면에서 본문과 기본 메뉴가 정상 표시된다.

미리보기에서 확인한 뒤 게시하기로 반영합니다. 실제 아임웹에 설치·접수·결제 검수한 상태는 아니므로 위 확인이 필요합니다.

## 12. 문제 해결

| 증상 | 해결 |
|---|---|
| 내용은 나오는데 디자인이 없다 | 공통 Header Code에 01-header-style 설치 여부 확인 |
| 상품 카드가 비어 있다 | Footer Code에 02-settings → 03-footer-runtime 순서 확인 |
| 이전 코드 헤더가 남아 있다 | 예전 긴 코드 위젯을 새 content 코드로 교체 |
| 코드가 너무 길다 | content 파일만 페이지에 넣었는지 확인; common은 공통코드 칸 |
| 상품 클릭 시 준비 중 안내 | productUrls에 실제 상품 URL 등록 |
| 문의가 접수되지 않는다 | 입력폼을 기본 위젯으로 추가했는지, 관리자 접수 설정 확인 |
| 이미지가 안 보인다 | 이미지 URL을 새 탭에서 열어 공개 접근 확인 |
| 수정한 상품이 일부 페이지에 반영 안 된다 | 모든 설정이 공통 02-settings 한 곳에 있는지 확인 |

기존 common/01-header-style.txt로 넣었던 시크릿루트 스타일 부분을 최신 파일 전체로 교체하세요. 다른 메타태그·분석 코드는 유지합니다. Footer Code와 페이지 본문은 다시 붙일 필요가 없습니다.

설정 저장·게시 후 Ctrl + F5로 새로고침하세요. CDN 접속이 차단되면 대체 폰트가 표시될 수 있습니다. 실제 아임웹 환경에서 최종 적용을 확인해야 합니다.
