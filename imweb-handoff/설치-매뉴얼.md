# 시크릿루트 의류 쇼핑몰
## 처음 사용하는 분을 위한 아임웹 설치 매뉴얼

**처음에는 메인 한 페이지만 붙여넣으세요. 화면이 잘 나오는 것을 확인한 뒤 나머지 페이지를 연결하면 됩니다.**

이 안내서는 현재 제공된 파일을 기준으로 작성했습니다. 아임웹 관리자 화면을 직접 확인한 매뉴얼은 아니므로, 일부 버튼 위치나 이름은 업데이트에 따라 다를 수 있습니다. 메뉴가 보이지 않으면 문서 끝의 공식 도움말을 함께 확인하세요.

---

## 0. 먼저 이해하기: 복붙으로 되는 것과 별도 설정이 필요한 것

| 하고 싶은 일 | 현재 파일로 가능한가요? |
|---|---|
| 주황색 쇼핑몰 디자인 표시 | 페이지별 코드를 붙여넣으면 됩니다. |
| 메뉴를 누르면 다른 페이지로 이동 | 아임웹에 해당 페이지를 만들고 주소를 맞추면 됩니다. |
| 상품 검색·필터·정렬 | 예시 상품 6개에 대해 동작합니다. |
| 상품 옵션 선택·수량 변경 | 시안에서 동작합니다. |
| 장바구니·찜하기 | 현재 브라우저에 저장하는 시안 기능입니다. |
| 실제 상품 등록·재고 관리 | 아임웹 쇼핑 관리자에서 등록해야 합니다. |
| 실제 주문·결제·회원가입 | 아임웹 기본 쇼핑·회원 기능을 사용해야 합니다. |

**현재 코드는 디자인과 동작을 확인하는 시안입니다. 복붙만으로 실제 판매 가능한 쇼핑몰이 완성되지는 않습니다.** 아래 1~7단계를 완료하면 시안을 아임웹에서 볼 수 있고, 8단계는 실제 판매를 준비하는 작업입니다.

## 1. 파일 준비하기

1. 제공받은 `secret-route-imweb-handoff.zip`을 컴퓨터에 저장합니다.
2. ZIP 파일을 마우스 오른쪽 버튼으로 누르고 **모두 압축 풀기**를 선택합니다.
3. 압축을 푼 위치에서 `imweb-handoff` 폴더를 엽니다.
4. 그 안의 `code-blocks` 폴더를 엽니다.
5. `index.txt` 파일을 메모장으로 엽니다. 연결 프로그램을 묻는다면 메모장을 선택합니다.

**지금 사용할 파일은 `code-blocks/index.txt`입니다.** 글자가 아주 많이 나오더라도 정상입니다. 먼저 내용을 지우거나 줄이지 마세요.

| 파일/폴더 | 용도 | 지금 필요한가요? |
|---|---|---|
| `code-blocks/index.txt` | 메인페이지 복붙 코드 | 예 |
| `code-blocks/shop.txt` 등 | 나머지 페이지 복붙 코드 | 메인 적용 후 |
| `assets/` | 로고·사진 원본 | 이미지 교체 시 |
| `CONFIG.example.json` | 설정 예시 | 참고용, 붙여넣지 않음 |
| `설치-매뉴얼.html` | 브라우저에서 보는 이 설명서 | 예 |

`index.html`은 컴퓨터·GitHub에서 보는 시안입니다. **아임웹 코드 위젯에는 `index.txt`의 내용을 붙여넣습니다.** ZIP 파일 자체를 코드 위젯에 업로드하지 않습니다. 이전 강의 사이트의 `archive-education-handoff` 폴더는 사용하지 않습니다.

## 2. 아임웹 디자인 모드 열기

1. 아임웹에 로그인합니다.
2. 작업할 사이트의 관리자 화면으로 들어갑니다.
3. **디자인 모드**를 엽니다.
4. 메뉴 목록에서 메인으로 사용할 페이지를 선택합니다.

기존 운영 사이트라면 먼저 현재 화면과 설정을 기록하고, 가능하면 별도 작업 페이지에서 확인하세요. 이 매뉴얼은 기존 내용을 삭제하라는 지시가 아닙니다.

**여기까지 완료되면:** 메인페이지의 디자인 편집 화면이 열려 있어야 합니다.

## 3. 메인페이지에 코드 위젯 넣기

1. 메인페이지에 코드를 넣을 빈 섹션을 준비합니다. 빈 섹션이 없다면 섹션을 추가합니다.
2. 위젯 추가 메뉴를 열고 **코드** 위젯을 선택합니다.
3. 추가된 코드 위젯 위에서 마우스 오른쪽 버튼을 누릅니다.
4. **코드 설정**을 엽니다.
5. 메모장의 `index.txt`에서 `Ctrl + A`를 누릅니다. 전체 글자가 선택됩니다.
6. `Ctrl + C`를 눌러 복사합니다.
7. 아임웹 코드 입력칸 안을 클릭합니다.
8. 입력칸에 기본 예시 코드가 있다면 그 입력칸 안에서만 `Ctrl + A`로 선택합니다.
9. `Ctrl + V`로 붙여넣습니다.
10. 설정창의 저장/적용 버튼으로 내용을 저장합니다.

**한 페이지에 같은 코드를 두 번 넣지 마세요.** 파일의 맨 위부터 맨 아래까지 전부 복사해야 합니다. `<style>`, `<script>` 부분도 포함합니다.

텍스트 위젯이나 HTML/CSS/JS 탭이 분리된 커스텀 위젯 스튜디오가 아니라 **일반 코드 위젯**을 사용하세요.

### 헤더와 푸터가 두 번 보이면

헤더는 로고와 메뉴가 있는 맨 위 영역, 푸터는 회사 정보가 있는 맨 아래 영역입니다. 아임웹 기본 헤더와 코드에 포함된 헤더가 동시에 표시될 수 있습니다.

초보자에게는 **아임웹 기본 헤더·푸터를 사용하고, 코드에 포함된 헤더·푸터를 숨기는 방식**을 권장합니다.

코드 입력칸에서 `showCustomHeader`를 검색해 아래처럼 바꿉니다. 검색이 어려우면 메모장에서 수정한 뒤 전체 코드를 다시 복사해 붙여넣으세요.

```javascript
"showCustomHeader": false,
"showCustomFooter": false,
```

`true`는 코드 헤더/푸터를 보여 주는 설정, `false`는 숨기는 설정입니다. 쌍따옴표와 쉼표는 그대로 유지합니다. 아임웹 기본 헤더에는 로고와 SHOP·신상품·베스트·컬렉션·고객센터 메뉴를 설정하고, 기본 푸터에는 회사 정보와 정책 링크를 넣습니다.

아임웹 기본 헤더가 표시되지 않는 페이지에서 두 값을 false로 바꾸면 상단 메뉴가 없어집니다. 이 경우 기본 헤더를 표시하거나, 코드 헤더를 다시 true로 바꾸세요. 둘 중 한 가지만 표시되면 됩니다.

### 화면 양옆과 위아래 여백 맞추기

코드가 들어간 섹션의 설정에서 배경을 흰색 또는 `#FFFCF8`로 맞추고, 불필요한 위·아래 여백을 줄입니다. 위젯을 섹션의 가로 폭 전체에 배치합니다. 코드 내부에는 이미 최대 본문 폭 1,240px과 모바일 여백이 설정되어 있습니다.

**여기까지 완료되면:** 미리보기에서 주황색 버튼, 메인 사진, 상품 카드가 보여야 합니다. 편집 화면에서 사진이나 애니메이션이 다르게 보이더라도 실제 미리보기 화면을 함께 확인하세요.

## 4. 메인 한 페이지 먼저 확인하기

1. 디자인 모드의 미리보기 기능을 엽니다.
2. PC 화면에서 로고·메인 배너·상품 카드가 보이는지 확인합니다.
3. 모바일 화면으로 바꾸어 글자와 상품 카드가 화면을 벗어나지 않는지 확인합니다.
4. 배너의 다음 버튼을 눌러 문구가 바뀌는지 확인합니다.

**이 단계에서 SHOP 메뉴를 눌렀는데 페이지가 없다고 나올 수 있습니다.** 아직 `/shop` 페이지를 만들지 않았기 때문입니다. 메인 디자인이 보이면 다음 단계로 진행합니다.

메인의 로고·사진은 기본적으로 공개된 GitHub 시안의 이미지 주소를 사용합니다. 처음 확인할 때는 이미지를 따로 업로드하지 않아도 됩니다. 실제 운영 전에 내 아임웹 이미지로 바꾸는 방법은 7단계에 있습니다.

## 5. 나머지 페이지 만들기

디자인 모드의 메뉴 관리에서 페이지/메뉴를 추가합니다. 페이지를 추가할 때 아래 표의 이름을 사용하고, 메뉴 설정의 주소(URL)를 맞춥니다. `/shop`은 내 사이트 주소 뒤에 붙는 부분입니다.

예를 들어 내 사이트가 `https://myshop.imweb.me`라면 SHOP 페이지는 `https://myshop.imweb.me/shop`입니다. 주소 입력칸이 전체 URL이 아니라 메뉴 주소만 받는 경우에는 해당 화면 형식에 맞춰 `shop` 또는 `/shop`을 입력하고, 저장 후 실제 주소를 확인하세요.

### 먼저 만드는 상단 메뉴

| 메뉴 이름 | 페이지 주소 | 붙여넣을 파일 |
|---|---|---|
| SHOP | `/shop` | `shop.txt` |
| 신상품 | `/new` | `new.txt` |
| 베스트 | `/best` | `best.txt` |
| 컬렉션 | `/collection` | `collection.txt` |
| 고객센터 | `/support` | `support.txt` |

### 상단에 노출하지 않아도 되는 연결 페이지

| 페이지 이름 | 페이지 주소 | 붙여넣을 파일 |
|---|---|---|
| 상품 상세 시안 | `/product` | `product.txt` |
| 찜한 상품 시안 | `/wishlist` | `wishlist.txt` |
| 장바구니 시안 | `/cart` | `cart.txt` |
| 브랜드 소개 | `/about` | `about.txt` |
| 배송·교환 안내 | `/shipping` | `shipping.txt` |
| 이용약관 | `/terms` | `terms.txt` |
| 개인정보처리방침 | `/privacy` | `privacy.txt` |

이 페이지들은 **메뉴에서 숨기되 링크로는 접근할 수 있도록** 설정합니다. 숨김과 접근 금지는 다르므로, 방문자가 URL로 접근할 수 있는지 미리보기에서 확인하세요.

각 페이지에서는 3단계를 반복합니다. 예를 들어 SHOP 페이지에는 코드 위젯을 넣고 `shop.txt` 전체를 붙여넣습니다. 신상품 페이지에는 `new.txt`를 넣습니다. `index.txt`를 모든 페이지에 넣으면 모든 페이지가 메인처럼 보입니다.

**메인은 사이트의 홈으로 지정하세요.** 현재 기본 코드의 홈 주소는 `/`입니다. 메인을 다른 주소에 만든다면 다음 단계에서 홈 링크도 수정해야 합니다.

`login.txt`, `signup.txt` 파일은 없습니다. 실제 회원가입·로그인은 아임웹 기본 회원 기능을 사용합니다. 현재 코드의 `/login`, `/signup`은 연결할 주소를 미리 적어둔 값이며, 모든 사이트에서 실제 회원 기능 주소라고 보장되는 값은 아닙니다.

## 6. 링크 주소 맞추기 — 필요한 경우에만 수정

5단계 표대로 페이지 주소를 만들었다면 대부분의 디자인 페이지 링크는 그대로 사용할 수 있습니다. 기존 페이지를 사용하거나 주소가 다르면 코드 안의 설정을 바꿉니다.

1. 수정할 TXT 파일을 메모장으로 엽니다.
2. `Ctrl + F`를 누릅니다.
3. `const CONFIG=`를 검색합니다.
4. 그 아래의 `links` 항목을 찾습니다.
5. **오른쪽 주소만** 실제 아임웹 주소로 바꿉니다.
6. 저장하고 파일 전체를 다시 복사해 해당 페이지의 코드 위젯을 교체합니다.

예를 들어 SHOP 페이지의 실제 주소가 `/shopping`이라면 다음과 같이 변경합니다.

```javascript
"shop.html": "/shopping",
```

왼쪽의 `shop.html`은 코드가 링크를 구분하는 이름이므로 그대로 둡니다. 오른쪽의 `/shopping`이 방문자가 이동할 실제 주소입니다.

아래처럼 전체 URL을 써도 됩니다. 자신의 사이트 주소로 교체하세요.

```javascript
"shop.html": "https://myshop.imweb.me/shopping",
```

**같은 설정을 사용하는 모든 코드 파일에서 수정해야 합니다.** 메인만 수정하면 다른 페이지에서는 이전 주소로 이동할 수 있습니다. `CONFIG.example.json`만 수정해도 실제 코드에는 반영되지 않습니다. 각 TXT 파일 안의 CONFIG를 수정해야 합니다.

### 로그인·장바구니 버튼 연결

아임웹에서 실제로 동작하는 회원·장바구니 버튼을 먼저 만들고, 해당 버튼이 이동하는 URL을 확인한 뒤 `login.html`, `signup.html`, `cart.html`, `wishlist.html`의 오른쪽 값에 입력합니다. 동작하는 URL을 찾기 어렵다면 기본 헤더의 회원/장바구니 요소를 사용하세요. 주소를 추측해서 입력하지 않습니다.

코드 헤더를 숨기고 기본 헤더를 사용하는 경우, 기본 헤더의 링크는 아임웹 헤더 설정에서 별도로 연결합니다.

### 상품 상세 시안 확인

상품 카드들은 `/product?id=1`부터 `/product?id=6`으로 이동합니다. `/product` 페이지에 `product.txt`를 넣으면 하나의 페이지에서 제품 번호에 맞춰 다른 상품을 보여 줍니다. `/product?id=1`이라는 메뉴를 따로 만들 필요는 없습니다.

사이트 설정이나 다른 앱이 `id`라는 주소 값을 사용한다면 실제 미리보기에서 상품이 맞게 열리는지 확인하세요. 이 주소 방식은 아직 아임웹 현장에서 검증되지 않았습니다.

## 7. 로고·사진을 내 아임웹에 올리기

처음 시안을 확인하는 단계는 기본 이미지 주소를 그대로 사용해도 됩니다. 운영을 준비할 때는 실제 상품 사진과 로고를 아임웹에 업로드하고 주소를 교체합니다.

### 이미지 주소 얻기

1. `assets` 폴더에서 업로드할 이미지를 확인합니다.
2. 아임웹의 이미지 위젯 또는 게시판의 이미지 첨부 기능을 이용해 이미지를 업로드합니다.
3. 업로드된 이미지가 보이는 미리보기/게시 화면에서 이미지 위에 오른쪽 클릭을 합니다.
4. 브라우저에 **이미지 주소 복사** 또는 비슷한 메뉴가 보이면 선택합니다.
5. 새 브라우저 탭에 그 주소를 붙여넣어 이미지 자체가 열리는지 확인합니다.

게시판을 활용했다면 로그인하지 않은 상태에서도 해당 이미지가 열리는지 확인합니다. 페이지 주소, 컴퓨터의 `C:\...` 경로, 이미지 파일 이름만 입력하면 안 됩니다.

### 코드에 주소 넣기

코드의 `"imageUrls": {}` 부분을 다음 모양으로 바꿉니다. 아래 `https://cdn.imweb.me/...`는 예시이므로 실제 주소로 교체합니다.

```javascript
"imageUrls": {
  "logo": "https://cdn.imweb.me/실제-로고-주소.png",
  "hero": "https://cdn.imweb.me/실제-메인사진-주소.jpg"
},
```

마지막 항목에는 쉼표를 넣지 않습니다. `imageUrls` 블록이 끝나는 `},`의 쉼표는 유지합니다. 한 장만 바꿀 때는 아래처럼 입력합니다.

```javascript
"imageUrls": {
  "logo": "https://cdn.imweb.me/실제-로고-주소.png"
},
```

| 설정 이름 | 적용 위치 | 제공 파일 |
|---|---|---|
| `logo` | 상단·하단 로고 | logo.png |
| `hero` | 메인 큰 사진 | hero.jpg |
| `editorial` | 컬렉션 소개 사진 | editorial.jpg |
| `shirt` | 예시 셔츠 사진 | shirt.jpg |
| `knit` | 예시 니트 사진 | knit.jpg |
| `denim` | 예시 데님 사진 | denim.jpg |
| `jacket` | 예시 재킷 사진 | jacket.jpg |
| `dress` | 예시 원피스 사진 | dress.jpg |
| `bag` | 예시 가방 사진 | bag.jpg |

키를 입력하지 않은 이미지는 기존 GitHub 사진을 사용합니다. 모든 이미지 주소를 지정했다면 기본 `assetBase`는 그대로 두어도 됩니다. 같은 이미지 설정을 해당 이미지를 사용하는 모든 페이지 코드에 반영하세요.

아임웹 기본 헤더를 사용한다면 그 헤더 로고는 기본 헤더 설정에서도 별도로 업로드해야 합니다. 코드의 logo 설정은 코드 안의 로고만 바꿉니다.

## 8. 실제 판매 가능한 쇼핑몰로 연결하기

**디자인 확인을 마친 뒤 진행합니다.** 현재 상품·옵션·가격은 예시이며 아임웹 상품 관리자와 자동으로 동기화되지 않습니다.

### 8-1. 실제 상품 등록

아임웹 관리자에서 쇼핑 상품 관리로 들어가 실제 상품을 추가합니다. 상품명, 판매가격, 대표사진, 상세설명, 색상/사이즈 옵션, 재고, 배송설정을 등록합니다. 상품 등록·결제 설정은 문서 끝의 공식 쇼핑몰 온보딩 안내를 참고하세요.

### 8-2. 상품 카드 → 아임웹 기본 상품 상세 연결

등록한 상품의 실제 상품 상세페이지를 열고 주소를 복사합니다. 코드에서 `"productUrls": {}`를 찾아 아래처럼 입력합니다.

```javascript
"productUrls": {
  "1": "https://내사이트주소/실제-상품1-주소",
  "2": "https://내사이트주소/실제-상품2-주소"
}
```

번호 1은 예시 셔츠, 2는 니트, 3은 데님, 4는 재킷, 5는 원피스, 6은 가방입니다. 실제 판매 상품과 맞게 연결하세요. 번호를 설정하지 않은 카드는 여전히 시안 상세페이지로 이동합니다.

설정하면 상품 카드를 눌렀을 때 시안 상세 대신 아임웹 기본 상품 상세로 이동합니다. **그 뒤의 옵션 선택·장바구니·구매는 아임웹 기본 화면을 사용합니다.** 코드로 만든 시안 상세의 구매 버튼이 실제 결제 버튼으로 바뀌는 것은 아닙니다.

### 8-3. 실제 장바구니·회원 기능 사용

아임웹 기본 헤더의 로그인·회원가입·장바구니 버튼을 사용하거나, 확인한 실제 기능 URL로 코드 링크를 변경합니다. 시안용 `/cart`, `/wishlist`, `/product` 페이지는 판매 흐름에서 제외합니다.

현재 카드의 하트 버튼은 시안 찜 기능입니다. `wishlist.html` 링크만 바꾸어도 그 하트 버튼이 아임웹 실제 찜으로 바뀌지는 않습니다. 실제 상품 찜을 운영하려면 아임웹 기본 상품/쇼핑 기능을 사용하도록 수정해야 합니다.

### 8-4. 상품이 많아질 때

현재 코드에는 상품 6개가 직접 적혀 있습니다. 실제 상품 관리자에서 가격을 바꿔도 코드 카드의 가격은 자동으로 바뀌지 않습니다. 상품 변경이 잦다면 목록은 **아임웹 기본 쇼핑 위젯**으로 구성하고, 메인 배너·컬렉션 소개 영역에 코드 디자인을 활용하는 방식이 운영하기 쉽습니다. 이는 추가 구현 작업이며 설정값 한 개로 전환되지는 않습니다.

### 8-5. 판매 시작 전 확인

실제 상품 사진·소재·세탁법·사이즈·배송·교환 정책과 사업자 정보를 등록합니다. 결제 서비스 연결 및 판매 설정을 마친 뒤 아임웹이 안내하는 테스트 절차로 주문 흐름을 확인합니다. 현재 제공된 약관/개인정보 페이지는 준비 중 안내이므로 운영 문서로 교체해야 합니다.
