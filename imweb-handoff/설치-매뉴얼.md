# 시크릿루트 의류 쇼핑몰 — 아임웹 설치

이 폴더가 최신 의류 쇼핑몰 설치본입니다. archive-education-handoff는 이전 강의 사이트 기록이며 사용하지 않습니다.

## 1. 페이지와 코드 위젯

디자인 모드에서 아래 페이지를 만들고, 일반 코드 위젯 한 개에 해당 TXT 파일 전체를 붙여넣습니다. 커스텀 위젯 스튜디오용이 아닙니다. 섹션 배경은 아이보리, 여백 0, 위젯은 전체 폭으로 배치합니다.

| 페이지 | 경로 | code-blocks 파일 |
|---|---|---|
| 메인 | / | index.txt |
| 전체 상품 | /shop | shop.txt |
| 신상품 | /new | new.txt |
| 베스트 | /best | best.txt |
| 컬렉션 | /collection | collection.txt |
| 상품 상세 시안 | /product | product.txt |
| 찜한 상품 시안 | /wishlist | wishlist.txt |
| 장바구니 시안 | /cart | cart.txt |
| 브랜드 | /about | about.txt |
| 고객센터 | /support | support.txt |
| 배송·교환 | /shipping | shipping.txt |
| 이용약관 | /terms | terms.txt |
| 개인정보처리방침 | /privacy | privacy.txt |

상품 상세는 /product?id=1부터 id=6까지 예시 제품을 표시합니다. 실제 판매에는 아임웹 상품 상세를 사용합니다.

## 2. 설정

각 코드에서 const CONFIG=를 검색해 설정합니다. 모든 페이지에서 동일하게 적용하세요.

- links: 오른쪽 URL을 실제 아임웹 주소로 변경합니다. 왼쪽 .html 키는 유지합니다.
- showCustomHeader, showCustomFooter: 아임웹 기본 헤더/푸터를 사용하면 false.
- assetBase: 기본값은 GitHub 시안 사진 폴더입니다. 호스팅이 없어지면 이미지가 표시되지 않습니다.
- imageUrls: assets의 사진을 아임웹에 업로드하고 logo, hero, editorial, shirt, knit, denim, jacket, dress, bag 키에 각각 실제 이미지 URL을 지정합니다. assetBase보다 우선 적용됩니다.
- productUrls: 실제 아임웹 상품 URL을 "1": "상품 URL"처럼 넣으면 카드가 실제 상품으로 이동합니다.

헤더·푸터에 사용자 제공 오렌지 상승 로고를 적용했습니다. assets/logo.png를 아임웹에 업로드하고 imageUrls의 logo 키에 이미지 URL을 지정하세요.

## 3. 실제 운영 연결

장바구니·찜은 브라우저 localStorage에 저장되는 시안입니다. 주문 접수·재고·배송·결제와 연동되지 않습니다. 로그인 화면도 실제 인증을 하지 않습니다.

아임웹 쇼핑에서 상품·옵션·가격·재고를 등록하고 상품 상세·장바구니·결제·회원 기능을 기본 기능으로 사용합니다. CONFIG의 links에서 cart/wishlist/login/signup을 실제 기능 URL로, productUrls를 실제 상품 URL로 변경합니다. 실제 운영 메뉴에서 시안 장바구니/회원 페이지는 제외합니다. 상품 동기화가 필요하면 기본 쇼핑 위젯을 사용하세요.

사진과 상품 정보는 실제 판매 제품이 아닌 예시입니다. 판매 전 실제 사진·소재·세탁법·실측·사업자 정보·배송·교환 정책·약관을 등록합니다.

## 4. 검수

모바일 메뉴, 검색·필터·정렬, 옵션 미선택 안내, 수량, 찜, 장바구니 수정·삭제, FAQ를 확인합니다. 실제 상품 URL 연결 후에는 아임웹 결제 흐름을 별도로 확인하세요.

파일 연결과 코드 문법 검사는 수행합니다. 실제 아임웹 설치·게시·검수는 아직 진행하지 않았습니다.
