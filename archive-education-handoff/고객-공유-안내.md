# 고객에게 시안 공유하기

## GitHub 계정이 없는 고객 — ZIP 전달

`secret-route-client-preview.zip`을 메일이나 메신저로 전달합니다. 고객은 압축을 푼 뒤 `index.html`을 브라우저로 열면 됩니다. GitHub 로그인은 필요하지 않습니다. ZIP 파일에는 공유 비밀번호가 설정되어 있지 않습니다.

전달 문구: “첨부한 시안 ZIP의 압축을 풀고 index.html을 열어 확인해 주세요. 메인과 메뉴별 상세페이지가 연결되어 있습니다. 강의·강사 정보는 예시이며, 실제 신청·결제·회원 기능은 아임웹 적용 시 연결할 예정입니다.”

## GitHub 계정이 있는 고객

저장소: https://github.com/ghddbwjd20-dotcom/secret-route-website

저장소는 비공개로 유지합니다. 고객의 GitHub 사용자명을 받아 저장소에 초대한 후, 고객이 초대를 수락해야 내용을 볼 수 있습니다. 저장소 접근 권한은 소스 파일과 변경 이력도 보여 주므로 검토 대상 고객에게만 부여합니다.

GitHub 저장소 링크는 웹사이트 실행 화면이 아닙니다. 고객은 GitHub 로그인 후 `Code → Download ZIP`으로 내려받고 압축을 풀어 `index.html`을 브라우저에서 열면 됩니다. 파일 하나만 내려받으면 다른 상세페이지로 이동할 수 없으므로 전체 ZIP을 전달합니다.

## 보낼 메시지

시크릿루트 홈페이지 시안 전달드립니다.

https://github.com/ghddbwjd20-dotcom/secret-route-website

GitHub 초대를 수락하신 뒤 저장소에서 Code → Download ZIP으로 내려받아 압축을 풀고, index.html을 열어 확인해 주세요. 메인과 메뉴별 상세페이지, 검색·필터·팝업 등 화면 인터랙션을 확인하실 수 있습니다.

강의·강사 정보는 예시이며 실제 신청·결제·회원 기능은 아임웹 적용 시 연결할 예정입니다. 디자인과 구성 위주로 검토 부탁드립니다.

## 아임웹 적용 담당자에게

ZIP의 `imweb-handoff` 폴더에 페이지별 복붙 코드와 설치 매뉴얼이 있습니다. 먼저 매뉴얼의 페이지 주소 표를 따라 메뉴를 만든 다음 각 코드 파일의 CONFIG를 설정해 붙여넣습니다.
