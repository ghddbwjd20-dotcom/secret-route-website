# 시크릿루트 웹사이트 시안

화이트·블랙·골드 톤의 반응형 강의 사이트 시안입니다. index.html을 열면 됩니다.

## 페이지
- 무료 특강 및 개별 강의 소개
- 프리미엄 강의 및 과정 준비 안내
- 무료 자료실 (체크리스트 다운로드)
- 강사 소개
- 로그인 / 회원가입 시안

## 운영 연결
강의와 강사 정보는 예시입니다. 신청, 결제, 로그인, 회원가입은 실제 동작하지 않습니다. 아임웹에 적용할 때 기본 입력폼, 회원, 쇼핑 기능에 연결해야 합니다. HTML 전체 파일은 미리보기용이며 코드 위젯 적용 시 본문과 스타일을 분리하고 로고를 아임웹에 업로드해야 합니다.

로고는 사용자 제공 이미지입니다.
