# 시크릿루트 아임웹 설치 매뉴얼

이 폴더는 기존 시안을 아임웹 **일반 코드 위젯**에 붙여넣기 위한 작업본입니다. 전체 HTML 문서가 아니라, 페이지별 HTML·CSS·JavaScript를 하나로 묶었습니다. 커스텀 위젯 스튜디오의 HTML/CSS/JS 탭용 코드는 아닙니다.

## 1. 폴더 구성

- `code-blocks/` : 페이지별 복붙 코드. `.txt` 파일을 열고 전체 선택 → 복사합니다.
- `assets/logo.png` : 아임웹에 업로드할 원본 로고.
- `CONFIG.example.json` : 설정 항목 참고용. 업로드하거나 실행하는 파일이 아닙니다.
- `설치-매뉴얼.md` : 이 안내서.
- `고객-공유-안내.md` : 비공개 GitHub 저장소를 고객에게 공유하는 방법과 메시지.

## 2. 아임웹 페이지 만들기

디자인 모드에서 아래 페이지를 만들고 메뉴 주소를 맞춥니다. 메뉴 주소 입력 방식은 관리자 화면에 따라 달라질 수 있으며, 저장 후 실제 페이지 URL을 확인합니다. 기존 페이지가 있다면 새로 만들지 않고 해당 URL을 코드의 CONFIG에 입력해도 됩니다.

| 페이지 | 기본 경로 | 붙여넣을 파일 |
|---|---|---|
| 홈 | `/` | `index.txt` |
| 무료 특강 | `/free-classes` | `free-classes.txt` |
| 프리미엄 강의 | `/premium` | `premium.txt` |
| 무료 자료실 | `/resources` | `resources.txt` |
| 강사 소개 | `/mentors` | `mentors.txt` |
| 특강 1 상세 | `/class-1` | `class-1.txt` |
| 특강 2 상세 | `/class-2` | `class-2.txt` |
| 특강 3 상세 | `/class-3` | `class-3.txt` |
| 프리미엄 안내 | `/premium-detail` | `premium-detail.txt` |
| 고객지원 | `/support` | `support.txt` |
| 이용약관 | `/terms` | `terms.txt` |
| 개인정보처리방침 | `/privacy` | `privacy.txt` |

상단 메뉴에는 무료 특강·프리미엄 강의·자료실·강사 소개만 노출하고, 상세·정책·고객지원 페이지는 메뉴에서 숨겨 링크로 접근하도록 구성합니다. 정책 페이지는 운영 문서를 작성하기 전까지 준비 중 안내입니다.

## 3. 페이지별 코드 붙여넣기

1. 대상 페이지에 빈 섹션을 만들고 코드 위젯을 추가합니다.
2. 코드 위젯 설정을 열고 해당 `.txt` 파일의 내용을 **전부** 붙여넣습니다.
3. 섹션 배경을 흰색으로, 불필요한 위·아래 여백을 0으로 설정합니다. 위젯은 섹션의 전체 가로 폭을 사용하게 배치합니다.
4. 저장 후 실제 미리보기에서 확인합니다. 편집 화면만으로 스크립트 동작을 판단하지 않습니다.
5. 같은 페이지에 같은 코드 블록을 두 번 넣지 않습니다. 한 블록 안에서 PC·모바일을 함께 처리합니다.

코드는 최대 본문 폭 1,180px로 구성되어 있습니다. 아임웹 섹션 폭이 더 좁으면 해당 섹션의 폭을 조정합니다. 스타일은 `.sr-site` 내부로 제한됩니다.

## 4. 로고와 주소 설정 — 각 코드 파일의 CONFIG

각 파일에서 `const CONFIG=`를 검색합니다. 설정은 파일별로 들어 있으므로 사용하는 모든 페이지에 동일하게 적용합니다. JSON 문자열은 쌍따옴표로 감싸고 항목 사이 쉼표를 유지합니다.

```javascript
"logoUrl": "https://cdn.imweb.me/upload/.../logo.png",
"showCustomHeader": true,
"showCustomFooter": true,
"loginUrl": "",
"signupUrl": ""
```

`assets/logo.png`를 아임웹 이미지 위젯 등에 업로드한 후 실제 이미지 주소를 복사하여 `logoUrl`에 넣습니다. 로고 주소가 비어 있으면 임시 텍스트 로고가 표시됩니다.

`links`의 왼쪽 키(`free-classes.html` 등)는 변경하지 않고 오른쪽 주소(`/free-classes` 등)만 실제 페이지 주소로 수정합니다. `.html` 파일을 아임웹에 업로드할 필요는 없습니다.

아임웹 기본 헤더를 사용할 때는 `showCustomHeader`를 `false`로 설정하고 기본 헤더에 로고·메뉴·로그인 버튼을 만듭니다. 기본 푸터를 사용하면 `showCustomFooter`도 `false`로 설정합니다. 기본 헤더와 코드 헤더가 동시에 나오지 않게 조정합니다.

`loginUrl`, `signupUrl`에는 사이트에서 확인한 실제 아임웹 회원 페이지 URL을 넣습니다. 비어 있으면 연결 준비 안내가 나타납니다. 기존 로그인·회원가입 HTML 시안은 이 설치 폴더에 포함하지 않았으며, 실제 인증을 대신하지 않습니다.

## 5. 실제 특강 신청 연결

1. 아임웹에 신청 페이지를 만들고 **기본 입력폼 위젯**을 배치합니다.
2. 필요한 항목과 실제 개인정보 수집·이용 안내를 설정합니다.
3. 테스트 신청이 관리자에게 접수되는지 확인합니다.
4. 각 상세 페이지 코드의 `applicationUrls`에서 해당 강의의 주소를 입력합니다.

```javascript
"applicationUrls": {
  "class-1": "/apply-class-1",
  "class-2": "/apply-class-2",
  "class-3": "/apply-class-3"
}
```

주소가 비어 있으면 신청 접수 전 안내 팝업이 표시됩니다. 링크를 입력하면 신청 버튼이 그 페이지로 이동합니다. 이 코드는 신청 데이터를 자체 저장하지 않습니다.

## 6. 유료 결제 연결

아임웹 쇼핑에서 실제 상품·가격·취소 및 환불 기준을 설정한 뒤 `premiumPurchaseUrl`에 상품 상세 URL을 넣습니다. 프리미엄 안내 페이지에 구매 이동 버튼이 추가됩니다. 현재 세 프리미엄 카드는 공통 준비 안내 페이지로 연결되므로 실제 과정 개설 시 과정별 페이지와 링크를 따로 구성해야 합니다.

구매자 전용 콘텐츠가 필요하면 아임웹 회원그룹·접근 권한도 설정합니다. 코드만 붙여넣는 것으로 결제·접근 제어가 생성되지는 않습니다.

## 7. 내용 수정과 인터랙션

- 강의 제목·소개·날짜·가격: 해당 코드 파일의 텍스트를 수정합니다. 홈, 목록, 상세에 중복된 내용도 함께 수정합니다.
- 배너 문구: HTML과 `setSlide()`의 문구를 함께 수정합니다.
- 강사: 현재는 프로필 준비 중입니다. 실제 이름·경력·사진으로 교체합니다.
- 자료실: 예시 체크리스트는 코드 안에서 TXT로 다운로드됩니다. 실제 PDF 등을 배포하려면 아임웹 파일 업로드 후 해당 링크로 교체합니다.
- 인터랙션: 배너 전환, 검색·분야 필터, 카드 호버, 스크롤 등장, 모바일 메뉴, FAQ 펼치기, 팝업, 맨 위로 이동을 포함합니다.

## 8. 게시 전 확인

PC와 모바일에서 메뉴 → 목록 → 상세 → 신청폼까지 이동해 확인합니다. 로고 로딩, 로그인·회원가입, 상품 링크, 다운로드, 모바일 메뉴, 팝업 닫기와 키보드 Escape도 확인합니다. 운영 문서와 사업자 정보, 강사·강의 정보, 신청 일정은 실제 내용으로 교체합니다.

로컬 파일에서는 링크·앵커 검사와 JavaScript 문법 검사를 진행했습니다. 실제 아임웹 사이트에 설치하여 동작을 검증한 상태는 아니므로, 적용 후 미리보기에서 확인해야 합니다. 본 작업에는 아임웹 로그인·실제 게시가 포함되지 않습니다.
