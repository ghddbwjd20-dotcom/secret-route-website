# 시크릿루트 의류 쇼핑몰 시안

고객 확인: https://ghddbwjd20-dotcom.github.io/secret-route-website/

밝은 아이보리와 주황 포인트의 의류 쇼핑몰입니다. 메인, 상품 목록, 신상품, 베스트, 컬렉션, 상품 상세, 장바구니, 찜, 회원 화면과 고객지원 페이지를 포함합니다.

상품명·사진·가격은 시안용입니다. 장바구니·찜은 현재 브라우저에 저장하며 실제 주문·결제·회원 기능은 아닙니다. 사진: Unsplash 대체 사진.

아임웹 코드: imweb-handoff. 이전 강의 설치본: archive-education-handoff (사용하지 마세요).

생성: node shop-build.cjs / node build-imweb.cjs

검사: node verify-shop.cjs
